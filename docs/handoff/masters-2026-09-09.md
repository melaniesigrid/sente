## Gotchas learned today

- Bash heredocs with large Python payloads break in this harness; write the script to
  the scratchpad with the Write tool and run it. Source files are CRLF in the working
  tree; the `edit()` helper pattern (decode, normalise to LF, edit, restore CRLF) is
  what worked.
- PowerShell `Tee-Object` and `Set-Content -Encoding utf8` write a BOM; strip it
  before Node parses the file.
- The Write tool refuses a path it has not Read in this session; files read via `cat`
  in another worktree do not count.
- `study_strong.py` must take the engine's main line (`study.mjs --emit-moves`), not a
  regex over the SGF, and compares colours in lowercase.
- On a symmetric position the eight transforms tie; `canonicalMove` takes the smallest
  index over the ties so mirrored moves merge in the book and count as agreement.
